# AI Dashboard

## Project Overview

AI Dashboard is an interactive data visualization and analytics application built using Streamlit, Pandas, and Plotly. The dashboard enables users to upload datasets, perform data cleaning, analyze key metrics, apply interactive filters, and explore data through dynamic visualizations.

## Features

* CSV File Upload
* Dataset Overview
* Data Cleaning and Preprocessing
* Key Performance Indicators (KPIs)
* Interactive Sidebar Filters
* Dynamic Bar Chart
* Dynamic Histogram
* Dynamic Pie Chart
* Dynamic Scatter Plot
* Dynamic Line Chart

## Installation

Install the required libraries:

pip install -r requirements.txt

## Instructions to Run the Project

Run the Streamlit application using:

streamlit run app.py

The application will open in your browser at:

http://localhost:8501

## Application Workflow

1. Upload the Superstore dataset.
2. View dataset overview and preview.
3. Perform data cleaning and preprocessing.
4. Explore key performance indicators (KPIs).
5. Apply interactive filters.
6. Analyze data using dynamic visualizations.
7. Generate insights from the dashboard.
